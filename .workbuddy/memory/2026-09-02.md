## UX 终裁（2026-09-02 晚六）

- 盟哥：不要 `agentsignal skills init`，直接 `agentsignal init`——起 web 向导询问配置（不要上来就走配置文件），MCP 服务自动集成。**「skills 不是我们的概念，是我们管理的流程/形式」**：复用 skills 包做管理检索，但不进用户心智。
- 用户面命令收敛四个：`agentsignal init`（向导+接线）/ `agentsignal mcp`（server，宿主配置引用）/ `agentsignal status` / `agentsignal uninstall`。检索/加载/verify 全部内化为 MCP 工具 + 引擎内部模块，不设 skills 用户命令树。
- config.json5 是产物不是入口：首次任何入口（init/mcp）无配置 → 起本地 web 向导（内置 http + 单页表单）问答生成。

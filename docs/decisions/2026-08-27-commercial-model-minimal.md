# 决议：商业模式极简三档（后置执行，2026-08-27）

站长原话裁定，取代此前 grilling 中所有商业化开放分支（Q1–Q6 的细则讨论全部不再进行）：

| 档 | 机制 | 一句话 |
|---|---|---|
| **个人·免费** | **反馈积分制**：每次有效 Outcome 反馈（[adoption]/[report]）获积分抵扣用量 | 个人默认免费，贡献即支付 |
| **企业空间** | 团队私有 Space 按**调用**收费 | 组织记忆是付费墙 |
| **私有部署** | 整套搬进企业内网，收部署费 | 大客户买安心 |

## 执行约束

1. **P1–P8 全程不见钱**：公共空间一律免费无限量，积分仅作记账概念——**Testnet/早期阶段不建积分表、不做任何结算系统**（防功能蔓延）；
2. 积分规则、企业调用的单价口径、部署报价三项细则推迟到 **P9 设计 / P10 上线前三个月**内各立一份细则决议，届时以真实留存数据定价；
3. 本决议生效后，商业话题在 Phase 1–4 的任何会议/文档中视为 closed —— 有人再提商业化 new feature，引本条拒绝。

# 决议：部署地域——海外先行（2026-08-27）

## 背景

原开放问题 O2：国内为主还是海外为主，影响域名解析、CDN 与合规链路。技术栈不受此约束（Docker Compose + PostgreSQL 两侧皆可运行）。

## 决议

1. **海外部署起步**：云服务器 + PostgreSQL 落在海外区（Vercel/Cloudflare/Fly 类托管或海外 VPS 自管均可），Docker Compose 编排。
2. `agentsignal.vip` DNS 直接解析至海外入口，**不走国内备案链路**；注册商侧只保留域名管理，解析迁至海外 DNS。
3. 目标受众定位为全球 Agent 生态；指标观测从第一天按国际流量假设设计（延迟、限频阈值不必迁就单一区域）。
4. 若日后出现国内用户密度需求，再评估独立合规实例或镜像节点，届时时另立决议——本决议不预支该路径的任何细节。

## 影响

- roadmap Phase 1 部署项锁定海外区域；W3 待决关闭。
- CI/CD、日志聚合等配套选型一律以海外可达性为先。

## 重点复核 B：5.3 zod default 工厂化语义等价

**✅ 等价成立，且整改确属必要**。8 处工厂（metrics/lifecycle 在 e9dd1cf，其余 6 处 dependencies/parameters/content/domains/arbitration/sync 在 241ba69）：

- **语义等价**：工厂输出与原字面量逐字段同形同值（arbitration 补 `as const` 恰为保住字面量类型不劣化）；唯一变化是 default 求值时机（每次 parse 新建）→ 引用隔离，default 行为不变。dist/index.js 已随 src 同步重建入册（8 处 `() =>` + retrieved/injected 均在）。
- **必要性实证**（node 22.22.2 + zod ^4.4.3 实测）：zod v4 对 default 值做**浅拷贝**——顶层对象/空数组字面量隔离，但**字面量内嵌的可变内容跨 parse 共享**（`{env:[]}` 的内嵌数组 push 串库；lifecycle 字面量的内嵌 metrics 对象 `retrieved += 1` 串库）——正是 5.3 红测暴露的生产级污染根因。工厂化后 schema-defaults.test.ts 三隔离用例全绿。
- **残余面安全**：全仓其余 `.default([])`/`.default(["common"])` 均为**顶层**数组（keywords/hosts/subscriptions/updates/checks/stack_rules/available 等），浅拷贝语义下 push 不串库，实测隔离——241ba69 的「6 处」口径恰好穷尽全部嵌套共享风险点，无漏网。

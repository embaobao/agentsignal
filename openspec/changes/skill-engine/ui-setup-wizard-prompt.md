# 功能提示词 — AgentSignal 本地 Web 管理界面设计规范

> 版本：v1（2026-09-02，对应 skill-engine 提案 v4+裁决 13）

## 任务

你是资深产品设计师 + 前端工程师（熟悉 shadcn / Base UI 审美、终端工具的 Web 界面范式）。请为下述产品输出一份**完整的界面设计规范**（design spec），供工程师直接照做。只输出规范文档本身，不要写实现代码。

## 产品背景

AgentSignal（agentsignal.vip）是「给 Agent 记忆」的基础设施。我们在做一个本地 CLI，命令名 `agentsignal`。CLI 内置一个**本地 Web 管理界面**：

- 由 `node:http` 在 `127.0.0.1` 随机端口拉起，自动打开浏览器，提交成功后服务自动关闭。
- 两种入口拉起同一界面：① 用户终端跑 `agentsignal init`；② Agent（IDE 里的 AI）调用 MCP 工具 `open_setup` 替用户拉起。
- 单页应用，两态切换：

### 状态 A · 无配置（首次使用）→ 初始化向导

1. **业务域**：多选（常见领域 chips + 自定义输入，如 化工 / 金融 / 前端 / DevOps）
2. **栈规则**：勾选启用（默认勾选 Next.js + TypeScript）
3. **宿主接线**：多选（系统已自动探测到的宿主列表打 ✓ 置顶，如 Claude Code / Cursor / Cline / Codex / Gemini CLI；未探测到的可手动勾选）
4. 提交 → 写配置 + 完成接线 → **完成页**：列出写入的每个宿主配置文件路径、下一步建议（「去 IDE 里直接问模型试试」）
5. 底部常驻：「使用默认配置直接开始」（对应 CI `--yes` 直通）

### 状态 B · 已有配置 → 管理/状态视图

- 配置摘要：业务域、栈规则
- 接线状态：每个宿主一行（已接线 ✓ / 未接线 ✗ / 配置漂移 ⚠）
- 本地库概况：条目数、索引上次重建时间、存储占用
- 效率指标：**双指标分列**——「吞吐节省」（估算进上下文前省掉的 token）与「残留占用」（会话末仍占窗口的部分）；注明「bytes/4 估算口径」，**不得宣传账单折扣或「任务完成自动滑出」**
- 操作区：重新运行向导、修复接线、（危险区，红色描边+二次确认）卸载并摘除全部宿主配置

## 硬约束（违反任何一条即不合格）

1. **单页 HTML，零外部依赖**：内联 CSS/JS，不引 React/框架/CDN/外部字体/图片；由 node:http 直接返回
2. 只绑 `127.0.0.1` 随机端口；无登录无鉴权（本地信任模型），但提交后立即关服
3. **术语红线**：全站文案**禁止出现「skills」一词**——这是内部实现概念。面向用户的措辞用「能力 / 指引 / 经验」或产品名
4. 全部简体中文文案；浅色主题；尊重 `prefers-reduced-motion`
5. 响应式：主视桌面（≥1024px），窄窗口（≥360px）不破版即可
6. 所有反馈即时可见：提交中/成功/失败三态；失败给出可操作的中文错误与重试入口
7. 向导支持返回上一步且已填项不丢失；中途关页不写任何配置（原子性）

## 交付物（设计规范文档，Markdown）

1. **信息架构**：两态页面结构树 + 状态流转图（文字描述）
2. **组件清单**：每个组件给出变体、尺寸、状态表（default/hover/active/disabled/error/loading）
3. **交互与反馈**：每个动作的前置条件、执行反馈、失败分支
4. **文案表**：逐条给出界面全部文案（含按钮、空态、错误、危险确认），符合术语红线
5. **视觉 tokens**：色板（语义色 + 中性阶）、字阶、间距、圆角、描边，用 CSS 变量形式给出
6. **线框图**：状态 A 三步向导 + 状态 B 视图 + 完成页 + 危险确认弹层，用 ASCII 或结构化文字描述
7. **边界情况**：探测不到任何宿主 / 全默认直通 / 端口被占用降级 / 配置文件被外部改坏 / 卸载二次确认

## 质量标准

- 工程师拿规范可以零提问开工
- 文案克制：不营销、不堆感叹号、指标如实
- 一个页面的认知负担 = 一个新用户 60 秒内能完成初始化
